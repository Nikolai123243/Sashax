# Boxing Champions - Página Web Moderna

Una página web moderna y responsive dedicada al mundo del boxeo profesional, con diseño atractivo y funcionalidades interactivas.

## 🥊 Características

- **Diseño Moderno**: Interfaz limpia y atractiva con temática de boxeo
- **Responsive**: Optimizado para dispositivos móviles, tablets y desktop
- **Interactivo**: Efectos de hover, animaciones y galería de imágenes
- **Navegación Suave**: Scroll suave entre secciones
- **Formulario de Contacto**: Validación y notificaciones
- **Galería de Fotos**: Lightbox para visualización de imágenes
- **Estadísticas Animadas**: Contadores animados para estadísticas

## 🚀 Tecnologías Utilizadas

- **HTML5**: Estructura semántica
- **CSS3**: Estilos modernos con Flexbox y Grid
- **JavaScript ES6+**: Funcionalidades interactivas
- **Font Awesome**: Iconos
- **Google Fonts**: Tipografía Roboto

## 🎨 Secciones de la Página

1. **Header**: Navegación fija con menú hamburguesa para móviles
2. **Hero**: Sección principal con título animado y botones CTA
3. **Boxeadores**: Tarjetas de boxeadores con estadísticas y ratings
4. **Eventos**: Timeline de próximos eventos y peleas
5. **Estadísticas**: Contadores animados con métricas del mes
6. **Galería**: Grid de imágenes con lightbox
7. **Contacto**: Formulario de contacto con validación
8. **Footer**: Enlaces y redes sociales

## 🎯 Funcionalidades JavaScript

- **Navegación Móvil**: Menú hamburguesa responsive
- **Scroll Suave**: Navegación entre secciones
- **Animaciones**: Efectos de entrada con Intersection Observer
- **Lightbox**: Galería de imágenes con zoom
- **Formulario**: Validación y notificaciones
- **Contadores**: Animación de estadísticas
- **Efectos Parallax**: Movimiento de fondo en scroll
- **Indicador de Progreso**: Barra de progreso de scroll

1. Abre `index.html` en tu navegador web

4. Prueba el formulario de contacto
5. Explora la galería de imágenes

## 🔧 Personalización

### Cambiar Colores
Modifica las variables CSS en `styles.css`:
```css
:root {
    --primary-color: #ff6b35;
    --secondary-color: #f7931e;
    --background-color: #0a0a0a;
}
```

### Agregar Boxeadores
Edita la sección `.fighters-grid` en `index.html` y agrega nuevas tarjetas de boxeadores.

### Modificar Eventos
Actualiza la sección `.events-timeline` con nuevos eventos.
